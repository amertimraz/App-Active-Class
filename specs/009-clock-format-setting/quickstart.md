# Quickstart / التحقق: تطبيق إعداد نظام الساعة (24 / 12)

**Feature**: 009-clock-format-setting

## المتطلبات

- جهاز/محاكي Android موصول، فلافور `direct`.
- بيانات فيها: طالب عليه دفعة مسجّلة، مجموعة لها جدول حصص (وقت بداية/نهاية)، وسجل حضور.
- `flutter build apk --debug --flavor direct` ثم `adb install -r ...`.

## سيناريو 1 — تطبيق فوري على الشاشة المفتوحة (US1)

1. الإعدادات → اضبط "نظام الساعة 24" = **مُفعّل**.
2. افتح تفاصيل طالب → تبويب المدفوعات. لاحظ وقت الدفعة (مثال: `2026-08-24  14:30`).
3. ارجع → الإعدادات → اقلب المفتاح لـ**12 ساعة**.
4. ارجع لتبويب المدفوعات.
   - **متوقّع**: الوقت بقى `2026-08-24  2:30 م` من غير إعادة تشغيل التطبيق.
5. بدّل بين تبويبات حضور/واجب/مدفوعات — كلها بالنظام الجديد.

## سيناريو 2 — تغطية كل نقاط العرض (US2)

بعد ضبط المفتاح على **12 ساعة**، تحقّق من كل نقطة:

| الشاشة | نقطة الوقت | متوقّع |
|--------|------------|--------|
| سجل الحضور (تفاصيل طالب / أرشيف) | وقت التسجيل | `h:MM ص/م` |
| مسح QR للحضور | `"في 2:30 م"` بعد تسجيل حضور | `h:MM ص/م` |
| طلبات الحجز | `"وصل ..."` | `h:MM ص/م` |
| تفاصيل المجموعة | `"آخر إرسال: ..."` لتقرير | `h:MM ص/م` |
| جدول الحصص | وقت بداية/نهاية الحصة | `h:MM ص/م` |
| شاشة المجموعات | وقت الحصة القادمة | `h:MM ص/م` |
| تقارير الدفعات | وقت الدفعة | `h:MM ص/م` |

ثم اقلب لـ**24 ساعة** وكرّر — كلها `HH:MM`.

## سيناريو 3 — الإشعارات (US2)

1. اضبط مجموعة لها حصة بعد أقل من ~20 دقيقة، المفتاح على **12 ساعة**.
2. من الإعدادات نفّذ ما يعيد جدولة الإشعارات (تغيير المفتاح يكفي).
3. استنى إشعار "🔔 حصة X بعد 15 دقيقة".
   - **متوقّع**: نص الإشعار `"الحصة الساعة 2:30 م"` (مش `14:30`).
4. (اختياري) إشعار "📅 حصص اليوم" الساعة 12 ص — كل سطر `اسم المجموعة الساعة h:MM ص/م`.

## سيناريو 4 — الثبات بعد إعادة التشغيل (US3 / عدم انحدار)

1. اضبط المفتاح على **12 ساعة**.
2. اقفل التطبيق بالكامل (swipe from recents) وافتحه.
   - **متوقّع**: المفتاح لسه 12 ساعة، وكل الأوقات `h:MM ص/م`.

## سيناريو 5 — حواف منتصف الليل / الظهر (SC-004)

بالمفتاح على **12 ساعة**، جهّز بيانات وقتها 00:15 و12:15:
- 00:15 → `12:15 ص`
- 12:15 → `12:15 م`

## فحص كود بعد التنفيذ (SC-003)

```bash
# ماينفعش يفضل أي سطر حيلة تحديث يدوية لإعداد الساعة جوه شاشة

# متوقّع: لا نتائج (كل القراءات بقت جوه ClockText/ClockBuilder/FormatHelper)
```
