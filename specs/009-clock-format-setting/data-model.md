# Data Model: تطبيق إعداد نظام الساعة (24 / 12)

**Feature**: 009-clock-format-setting

## نظرة عامة

**لا يوجد أي تغيير في نموذج البيانات.** الميزة إصلاح في طبقة العرض فقط.

## الكيان القائم (بدون تعديل)

### إعداد نظام الساعة

| الخاصية | القيمة |
|---------|--------|
| مفتاح التخزين | `use_24h_time_format` في جدول `app_settings` |
| النوع | نص `'1'` / `'0'` ↔ `bool` |
| الافتراضي | `true` (24 ساعة) |
| القراءة | `SettingsController._loadUse24hFormat()` عند الإقلاع → `RxBool use24hFormat` |
| الكتابة | `SettingsController.setUse24hFormat(bool)` → يحفظ + (جديد) يعيد جدولة الإشعارات |

**قرارات التحويل** (منطق عرض، مش تخزين):

- 24 ساعة: `HH:MM` (صفر بادئ، 00–23).
- 12 ساعة: `h:MM` + دلالة `ص` / `م` (بدون صفر بادئ للساعة).
- 00:00–00:59 → `12:MM ص`.
- 12:00–12:59 → `12:MM م`.
- 13:00 → `1:00 م`.

## بدون هجرة قاعدة بيانات

`DATABASE_VERSION` يفضل زي ما هو. لا جداول/أعمدة جديدة.
