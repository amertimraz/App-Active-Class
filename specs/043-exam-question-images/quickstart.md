# Quickstart: التحقق من صور أسئلة الامتحان

## المتطلبات المسبقة
- `supabase/migration_exam_question_images.sql` مُطبَّقة على السيرفر.
- `DATABASE_VERSION = 36` وفرع `oldVersion < 36` موجود.
- امتحان تجريبي + طالب تجريبي (كود + آخر 4 أرقام تليفون) لأداء الامتحان من متصفح فعلي على `booking_site/exam/`.

## اختبارات الوحدة — `test/exam_question_images_test.dart`
```bash
flutter test test/exam_question_images_test.dart
```
1. `alignOptionImages`: قائمة أقصر/أطول من `options` → تتصحّح للطول الصحيح.
2. `addOptionImageSlot`: يضيف `null` في الآخر، الأصل بلا تغيير.
3. `removeOptionImageSlot`: يشيل بالـindex الصحيح، الباقي بنفس الترتيب.
4. `ExamQuestion.toCloudMap`: يحتوي `optionImageUrls` لو فيه صورة واحدة على الأقل، **ولا يحتوي** `explanationImageUrl` أبدًا.
5. `ExamQuestion.fromMap`: صف قديم (عمود فاضي) → قائمة null بطول `options`.

## التحقق اليدوي
1. **القص (US1)**: في محرّر امتحان، أضف صورة سؤال من المعرض → تظهر شاشة قص قبل أي رفع. كبّر/اسحب واعتمد → الصورة المرفوعة هي الجزء المقصوص. افتح تاني وألغِ القص → الصورة القديمة (لو موجودة) بلا تغيير.
2. **صورة الشرح (US2)**: اكتب شرح نصي + صورة لسؤال. اعتمد درجة طالب سلّم → افتح رابط نتيجته: النص والصورة ظاهرين مع بعض. لطالب لسه مش معتمد: افتح رابطه → لا نص ولا صورة شرح. احذف الصورة بس (سيب النص) → الصورة تختفي من مراجعة طالب جديد، النص يفضل.
3. **صور الاختيارات (US3)**: أضف صورة لاختيارين من أصل 4 في سؤال، وانشر الامتحان. افتح رابط الامتحان من متصفح كطالب → صورة كل اختيار ظاهرة جنب نصه **قبل** التسليم. سلّم واعتمد الدرجة → افتح رابط المراجعة → نفس الصور ظاهرة. احذف اختيار بصورة من المحرّر → صورته تختفي معاه، باقي الاختيارات وصورها سليمة.
4. **المعاينة**: افتح معاينة الامتحان قبل النشر → صورة الشرح وصور الاختيارات ظاهرة للمدرّس بنفس شكل ظهورها للطالب لاحقًا.
5. **بنك الأسئلة (FR-012)**: أضف سؤال بصور (شرح + اختيارات) للبنك، ثم أضفه لامتحان من "أضف من البنك" → كل الصور وصلت للنسخة الجديدة.
6. **فشل التحميل (SC-005)**: افصل الإنترنت لحظة تحميل صفحة الامتحان (أو استخدم رابط صورة مكسور) → مكان الصورة يظهر "تعذّر تحميل الصورة" وباقي الامتحان يفضل شغّال وقابل للتسليم.
7. **صورة السؤال القديمة**: تأكد إنها لسه بتشتغل بنفس الشكل القديم تمامًا (بلا أي تغيير سلوكي) مع وجود صور اختيارات جنبها.
