# Data Model: إرسال نتيجة الامتحان لولي الأمر عبر واتساب

لا كيانات تخزين جديدة — الميزة تعيد استخدام الكيانات الموجودة بالكامل وتُنشئ نصًا مؤقتًا (غير مخزَّن) وقت الإرسال فقط.

## الكيانات الموجودة المُستخدَمة

### `ExamGrade` (`lib/models/exam_grade_model.dart`) — بدون تغيير بنيوي

| الحقل المُستخدَم | الغرض في هذه الميزة |
|---|---|
| `studentId` | لتحديد الطالب ورقم ولي أمره عبر خريطة الطلاب المُحمَّلة |
| `studentName` | اسم الطالب في نص الرسالة |
| `grade` | الدرجة المُحقَّقة — `null` يعني "لسه مش متسجّلة" (زر الإرسال معطّل/مخفي) |
| `isAbsent` | لو `true`، الرسالة تكون رسالة غياب بدل نتيجة درجة |
| `notes` | تُضاف للرسالة لو موجودة (غير فارغة) |
| `maxGrade` / `passingGrade` | لحساب "الدرجة من كام" وحالة النجاح/الرسوب |
| `isEntered` (getter موجود) | شرط ظهور/تفعيل زر الإرسال (لازم `true`) |

### `Exam` (`lib/models/exam_model.dart`) — بدون تغيير

| الحقل | الغرض |
|---|---|
| `name` | اسم الامتحان في نص الرسالة |

### `Student` (`lib/models/student_model.dart`) — بدون تغيير

| الحقل | الغرض |
|---|---|
| `guardianPhone` | رقم ولي الأمر المُرسَل إليه — `null`/فاضي بعد التنضيف يعني "تخطي" |
| `name` | احتياطي/تأكيد (الاسم الأساسي في الرسالة من `ExamGrade.studentName`) |

## كيان مؤقت جديد (غير مخزَّن)

### رسالة نتيجة ولي الأمر (Guardian Exam Result Message)

نص عادي يُبنى وقت الضغط على زر الإرسال (فردي أو ضمن حلقة الإرسال الجماعي)، ولا يُحفَظ في أي جدول. يتكوّن من:

- اسم الطالب
- اسم الامتحان
- **إما**: "الدرجة: X من Y" + "الحالة: ناجح/راسب" (+ الملاحظات لو موجودة) — لو `grade != null`
- **أو**: نص غياب مستقل ("لم يحضر امتحان [اسم الامتحان]") — لو `isAbsent == true`

## خريطة مساعدة وقت التشغيل (State محلي في الشاشة، لا تخزين)

`Map<int, Student> _studentsById` — تُحمَّل مرة واحدة عند فتح `ExamGradesPage` (طلاب المجموعة الحالية)، تُستخدَم لجلب `guardianPhone` لكل `studentId` بدون استعلام DB منفصل لكل زر إرسال.
