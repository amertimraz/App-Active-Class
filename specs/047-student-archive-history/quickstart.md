# Quickstart: سجل أرشفة الطالب

## اختبارات وحدة
```bash
flutter test test/archive_history_test.dart
```
تغطي: الدمج والترتيب (تواريخ مختلفة/متساوية)، الصيغة (اليوم/أمس/تاريخ كامل، ص/م)، `shouldRecordArchiveEvent`، `archiveEventVisible` (فلتر الحالة/البحث/المجموعة)، تكرار أرشفة/إعادة.

## تحقق يدوي (جهاز)
1. أرشف طالب → تفاصيله ← سجل الحضور: سطر "تمت أرشفته — اليوم …" بالأيقونة المحايدة.
2. استعده → سطر "أُعيد من الأرشيف"؛ كرر أرشفة/إعادة → 4 أحداث بالترتيب.
3. نسبة الحضور وعدّادات حاضر/غائب في الأعلى ما اتغيّرتش.
4. شاشة الحضور ← السجلات: السطور ظاهرة مع "الكل" ومخفية مع فلتر حاضر/غائب/متأخر.
5. طالب كان مؤرشف قبل التحديث: سطر أرشفة بتاريخه القديم.
6. وضع الفريق: أرشف من جهاز → يظهر عند الآخر بعد المزامنة، بدون تكرار.
7. حذف الطالب نهائيًا → الأحداث تختفي.
