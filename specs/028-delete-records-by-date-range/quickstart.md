# Quickstart / Validation: حذف السجلات بمدى تواريخ

## اختبارات آلية

```bash
flutter test test/delete_records_range_test.dart
flutter test
flutter analyze
```

متوقَّع: كل الاختبارات تعدّي (8 حالات للدالة)، `analyze` بلا مشاكل جديدة فوق الـbaseline.

## سيناريوهات يدوية

### 1 — حذف حضر فترة قديمة (النوع الأساسي)
حضّر بيانات: حضور + دفعات + امتحانات عبر أكتر من فترة. الإعدادات → "حذف سجلّات بمدى تواريخ" → "من" و"إلى" لفترة قديمة → اختر "سجل الحضور" و"الدفعات" → "معاينة".
**متوقَّع**: بطاقة بأعداد دقيقة لكل نوع + إجمالي.
اضغط "حذف نهائيًا" → حوار تأكيد → أكّد.
**متوقَّع**: نسخة احتياطية اتعملت (تظهر في شاشة إدارة النسخ)، ثم رسالة "اتحذف: N حضور، M دفعة". سجلّات الفترة اختفت، بقية الفترات + الامتحانات سليمة.

### 2 — الإجمالي صفر
مدى مفيهوش أي سجلّات من الأنواع المختارة → "معاينة".
**متوقَّع**: "لا سجلّات مطابقة"، زر "حذف" معطّل.

### 3 — تأكيد بكتابة للكميات الكبيرة
مدى فيه أكتر من 100 سجل مختار → "حذف نهائيًا".
**متوقَّع**: الحوار فيه حقل كتابة؛ زر "حذف" معطّل حتى تكتب "حذف".

### 4 — فشل النسخة الاحتياطية → إلغاء
(محاكاة: مساحة تخزين ممتلئة أو قاعدة غير موجودة.) أكّد الحذف.
**متوقَّع**: "اتلغى الحذف: فشل النسخة الاحتياطية"، صفر سجلّات اتحذفت.

### 5 — عدم انحدار المجموعات الشهرية / بيانات الروستر
بعد أي حذف: افتح شاشة الطلاب والمجموعات.
**متوقَّع**: كل الطلاب والمجموعات موجودين — لا شيء منهم اتحذف.

### 6 — الامتحانات + توابعها
اختر "الامتحانات" لمدى فيه امتحان له درجات وربط بمجموعات → احذف.
**متوقَّع**: الامتحان + درجاته + ربطه اختفوا. امتحانات خارج المدى سليمة.

### 7 — درجات فقط
اختر "درجات الامتحانات" فقط لنفس المدى → احذف.
**متوقَّع**: الدرجات اختفت، الامتحانات نفسها موجودة.

### 8 — مزامنة الفريق في الاتجاهين (جهازان)
جهاز مدرّس + مساعد في وضع الفريق. المدرّس يحذف حضور فترة.
**متوقَّع**: بعد المزامنة، نفس السجلّات اختفت عند المساعد ولا ترجع.
كرّر بالعكس: المساعد يحذف → يختفي عند المدرّس.

### 9 — سجلّات التقارير (غير مُزامنة)
اختر "سجلّات تقارير واتساب" لمدى → احذف (مع وضع الفريق مفعّل).
**متوقَّع**: تُحذف محليًا؛ لا تؤثّر على أجهزة الفريق (غير مُزامنة أصلًا).
