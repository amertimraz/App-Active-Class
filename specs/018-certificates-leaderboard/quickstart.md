# Quickstart — تحقّق يدوي: شهادات تقدير + المراكز

`flutter analyze` صفر تحذيرات + تحقّق يدوي (نمط specs 009–017).

## متطلبات مسبقة

- امتحان ورقي فيه ≥ 5 طلاب، بعضهم فوق درجة النجاح وبعضهم تحتها وواحد غائب.
- امتحان إلكتروني منشور + مصحَّح + درجات معتمَدة (لـ US3).
- اسم المدرس والتخصص متعبّيين في الإعدادات (وجرّب كمان وهم فاضيين).
- عدة امتحانات في شهور مختلفة (لفلتر الشهر).

## بناء وتشغيل

```bash
flutter analyze
flutter run --flavor direct
```

## سيناريوهات

### 1. شهادات لكل الناجحين في امتحان (US1)
1. افتح شاشة درجات الامتحان → زر "شهادات تقدير".
2. تأكد: القائمة فيها الطلاب فوق درجة النجاح فقط، **مش** الغائب ولا الراسبين، وكلهم معلَّمين.
3. شيل العلامة عن طالب، بدّل القالب لـ"حديث"، اضغط "توليد".
4. تأكد: PDF فيه صفحة لكل طالب مختار، كل شهادة باسم الطالب الصح ودرجته، واسم المدرس وتخصصه.
5. "مشاركة" → تفتح ورقة النظام بالملف.
6. **الإعدادات فاضية**: امسح اسم المدرس/التخصص، ولّد تاني → الشهادة سليمة بدون سطور "المعلّم: " فارغة.
7. امتحان مفيهوش أي ناجح → رسالة "مفيش طلاب فوق درجة النجاح".

### 2. شهادة طالب واحد (US1 / FR-008)
- صفحة الطالب → زر "شهادة تقدير" → يختار امتحان ناجح فيه → PDF صفحة واحدة.

### 3. صفحة المراكز (US2)
1. افتح "الأوائل" — الفلتر "الكل": كل الطلاب مرتّبين بالنسبة تنازليًا، أول 3 بميداليات، **المؤرشفون مش ظاهرين**.
2. بدّل لـ"مجموعة: [اسم]" → طلاب المجموعة دي بس.
3. بدّل لـ"امتحان: [اسم]" → الترتيب بدرجة الامتحان ده.
4. بدّل لـ"شهر: [شهر]" → الترتيب بامتحانات الشهر ده (بشهر التقرير، مش تاريخ الامتحان).
5. طالبين بنفس النسبة → ترتيبهم ثابت (بالاسم) — أعد فتح الصفحة، نفس الترتيب.
6. زر "مشاركة قائمة الأوائل" → نص واتساب فيه أول N بترتيبهم ونسبهم واسم المدرس.
7. "شهادات المراكز" → 3 شهادات (أول/ثاني/ثالث) بنطاق الفلتر في نص الإنجاز.
8. اختار فلتر شهر مفيهوش امتحانات → "مفيش امتحانات في [شهر]".

### 4. مشاركة نتائج الامتحان الإلكتروني (US3)
1. شاشة نتائج امتحان إلكتروني فيه درجات معتمَدة → زر "إرسال النتائج واتساب".
2. تأكد: بس الطلاب **المعتمَدين** في قائمة الإرسال (مش "بانتظار الاعتماد").
3. أرسل لطالب → رسالة واتساب فيها درجته وناجح/راسب (نفس صيغة الورقي).
4. طالب معلَّم "غائب" → رسالة غياب مستقلة.

### 5. صفر تراجع (SC-007)
- شاشات الدرجات، صفحة الطالب، التقارير — كلها زي ما هي + الأزرار الجديدة.
- `DATABASE_VERSION` لسه 23، مفيش migration.
- صفحة الأوائل هي الوحيدة اللي اتغيّر شكلها.

## بوابة القبول
