# قوالب واتساب (للتقديم في WhatsApp Manager)

**التقديم**: [WhatsApp Manager](https://business.facebook.com/wa/manage/message-templates/) ← Message templates ← Create template.
لكل قالب: **Category = Utility**، **Language = Arabic (ar)**، الاسم بالظبط زي الجدول (الـ worker بيستخدم الأسماء دي في `src/templates.js`).

قواعد Meta اللي اتراعت: المتغير مش في أول النص ولا آخره، مفيش محتوى ترويجي، كل متغير ليه مثال، وبدون سطور متتالية فاضية.
نص "للإيقاف رد بكلمة إيقاف" في الفوتر بيدعم شرط الإيقاف (FR-006).

---

## 1) `ac_absence_ar` — تنبيه غياب
**Body:**
```
السلام عليكم، نفيدكم بأن الطالب {{1}} تغيّب عن حصة مجموعة {{2}} بتاريخ {{3}}. مع تحيات {{4}}.
```
**Footer:** `للإيقاف رد بكلمة إيقاف`

| المتغير | المحتوى | مثال للتقديم |
|---|---|---|
| {{1}} | اسم الطالب | أحمد محمد |
| {{2}} | اسم المجموعة | الصف الثالث - أ |
| {{3}} | التاريخ | 2026-11-09 |
| {{4}} | اسم المدرس | أ/ سعد |

---

## 2) `ac_late_payment_ar` — تذكير تأخر دفع
**Body:**
```
السلام عليكم، نذكّركم بوجود مبلغ مستحق على الطالب {{1}} قدره {{2}} جنيه. برجاء السداد في أقرب وقت. مع تحيات {{3}}.
```
**Footer:** `للإيقاف رد بكلمة إيقاف`

| المتغير | المحتوى | مثال |
|---|---|---|
| {{1}} | اسم الطالب | أحمد محمد |
| {{2}} | المبلغ المتأخر | 150 |
| {{3}} | اسم المدرس | أ/ سعد |

---

## 3) `ac_receipt_ar` — إيصال دفعة
**Body:**
```
السلام عليكم، تم استلام مبلغ {{1}} جنيه عن الطالب {{2}} لشهر {{3}}. المتبقي: {{4}} جنيه. شكرًا لكم، {{5}}.
```
**Footer:** `للإيقاف رد بكلمة إيقاف`

> ترتيب المتغيرات هنا مطابق لـ `supabase/wa-worker/src/templates.js` (`amount, student, month, remaining, teacher`).

| المتغير | المحتوى | مثال |
|---|---|---|
| {{1}} | المبلغ المدفوع | 200 |
| {{2}} | اسم الطالب | أحمد محمد |
| {{3}} | الشهر | نوفمبر |
| {{4}} | المتبقي | 0 |
| {{5}} | اسم المدرس | أ/ سعد |

---

## ملاحظات
- المراجعة بتاخد من دقايق لأيام. لو اترفض قالب، Meta بتكتب السبب؛ عدّل الصياغة وقدّمه تاني.
- التعديل بعد الاعتماد بيحتاج اعتماد جديد، فخلّي النص نهائي قبل التقديم.
- نص `{{4}}` المتبقي "0" مقبول كمتغير نصي.
- نص الرسالة اللي المدرس مخصصه في التطبيق (SystemMessages) بيُستخدم للإرسال اليدوي بس.
