# قوالب واتساب (للتقديم في WhatsApp Manager)

**التقديم**: [WhatsApp Manager](https://business.facebook.com/wa/manage/message-templates/) ← Message templates ← Create template.
لكل قالب: **Category = Utility**، **Language = Arabic (EGY)** (كود `ar_EG`، والـworker بيبعت بنفس الكود)، الاسم بالظبط زي الجدول (الـ worker بيستخدم الأسماء دي في `src/templates.js`).

قواعد Meta اللي اتراعت: المتغير مش في أول النص ولا آخره (لازم فيه كلام بعد آخر متغير، وإلا Meta ترفض بخطأ «يجب ألا تكون المتغيرات في بداية القالب أو نهايته»)، مفيش محتوى ترويجي، كل متغير ليه مثال، وبدون سطور متتالية فاضية (سطر فاضي واحد بين الفقرات بس). المتغيرات بتظهر في النص بالترتيب {{1}} ثم {{2}} ثم {{3}}…، والنجمتين `*...*` بتعمل خط عريض، والأيقونات إيموجي عادي.
نص "للإيقاف رد بكلمة إيقاف" في الفوتر بيدعم شرط الإيقاف (FR-006).

---

## 1) `ac_absence_ar` — تنبيه غياب
**Body:**
```
⚠️ *تنبيه غياب*

👤 الطالب: {{1}}
👥 المجموعة: {{2}}
📅 التاريخ: {{3}}

لم يحضر الطالب هذه الحصة، برجاء المتابعة.

👨‍🏫 {{4}}
📞 للتواصل: {{5}}

شكرًا لتعاونكم 🌷
```
**Footer:** `للإيقاف رد بكلمة إيقاف`

| المتغير | المحتوى | مثال للتقديم |
|---|---|---|
| {{1}} | اسم الطالب | أحمد محمد |
| {{2}} | اسم المجموعة | الصف الثالث - أ |
| {{3}} | التاريخ | 2026-11-09 |
| {{4}} | اسم المدرس | أ/ سعد |
| {{5}} | رقم المدرس للتواصل | +201012345678 |

**Body:**
```

💵 المبلغ المدفوع: {{1}} جنيه
👤 الطالب: {{2}}
📅 الشهر: {{3}}
```

## ملاحظات
- المراجعة بتاخد من دقايق لأيام. لو اترفض قالب، Meta بتكتب السبب؛ عدّل الصياغة وقدّمه تاني.
- التعديل بعد الاعتماد بيحتاج اعتماد جديد، فخلّي النص نهائي قبل التقديم.
- نص `{{4}}` المتبقي "0" مقبول كمتغير نصي.
- نص الرسالة اللي المدرس مخصصه في التطبيق (SystemMessages) بيُستخدم للإرسال اليدوي بس.
