# Quickstart: تقرير الأداء

## اختبارات وحدة
```bash
flutter test test/performance_test.dart
```
تغطي: النسب الأربعة (حدود، غياب الامتحان، الفراغ)، `trendOf` عند الحد ±3، `levelOf` عند 85/75/65/50، `monthsBack` (عبر السنة)، `buildPerformance` (مؤشرات مفعّلة فقط، شهر بلا سابق)، `rankPerformances` (بلا بيانات في الآخر، فلتر المتراجعين)، `performanceMessage` (بلا مبالغ، التوقيع، الأسهم)، `performancePortalFields`.

## تحقق يدوي (جهاز)
1. طالب بامتحانات سبتمبر 60% وأكتوبر 70% → تفاصيل الطالب ← "الأداء": الامتحانات 70% ↑ +10.
2. رسم 6 شهور: الشهور الفاضية فجوة؛ الضغط على مؤشر يعرض قيمه.
3. إرسال نصي → واتساب برسالة فيها المؤشرات والأسهم والتوقيع، بدون أي مبلغ.
4. إرسال صورة كارت → معاينة ثم مشاركة PNG مقروءة؛ PDF صفحة واحدة.
5. مجموعة ← "الأداء": الترتيب صحيح، فلتر "المتراجعين"، بلا بيانات في الآخر.
6. إرسال جماعي: ملخص (يتبعت/يتخطّى) ثم الرسائل واحدة واحدة.
7. أقفل سويتش الواجب/التسميع → يختفي المؤشر من الشاشة والرسالة والكارت والـPDF والبوابة.
8. مساعد بلا صلاحية الأكاديميات → قفل.
9. بوابة مفعّلة → قسم "مستوى الطالب" عند ولي الأمر بعد النشر.
