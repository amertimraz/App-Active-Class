# Quickstart / Validation: تناسق التقارير

**Feature**: 013-reports-consistency | نفس نهج التحقّق اليدوي في specs 009–012.

## المتطلبات

- `flutter analyze` نضيف.
- جهاز فيه: طالب مؤرشف عليه مديونية، مجموعة بيها ~8 تسجيلات حضور الشهر اللي فات،
  امتحان قديم، القدرة على تغيير تاريخ الجهاز.
- تحقّق migration v21→v22 (تثبيت فوق نسخة قديمة).

## السيناريوهات

### 1. المؤرشف مستبعد من شاشة التقارير (US1)
1. أرشف طالب عليه مديونية.
2. افتح شاشة التقارير → **مش موجود** في "المتأخرين ما دفعوش" ولا ملخّص المجموعات ولا تفصيل الحصص.
3. صدّر تقرير PDF → أرقامه مش داخلة في أي إجمالي.
4. استرجع الطالب → يرجع يظهر.
5. إجماليات المجموعة (المتوقع/المحصّل) نقصت بمقدار حصّته.

### 2. شهر شاشة التقارير الافتراضي (US2)
1. خلّي تاريخ الجهاز **2 سبتمبر**، افتح شاشة التقارير → الشهر المعروض = **أغسطس**.
2. خلّي التاريخ **20 سبتمبر** (والتحصيل مقدّم) → الشهر = **سبتمبر**.
3. فعّل "التحصيل المؤخّر" (spec 012)، تاريخ 20 سبتمبر → الشهر = **أغسطس**.
4. غيّر الشهر يدويًا لسبتمبر ثم تنقّل — اختيارك يُحترَم (الافتراضي أول فتح بس).

### 3. منتقي شهر في تقرير الواتساب (US3)
1. تاريخ 2 سبتمبر، مجموعة → "إرسال تقرير واتساب".
2. الموديل يفتح على **منتقي شهر فوق القائمة**، مختار **أغسطس**، الخيارات تنتهي عند أغسطس.
3. اختر يوليو → ابعت لطالب → الرسالة فيها حضور/واجب/مدفوعات/**امتحانات** يوليو بالظبط.
4. غيّر لأغسطس → حالة "تم الإرسال" تتحدّث للشهر ده.
5. نفس المنتقي في: الإرسال الجماعي من الإعدادات، وزر "تقرير شهري" في صفحة الطالب.

### 4. كارت الدفعات في الداشبورد (US4)
1. تاريخ 2 سبتمبر → الكارت عنوانه **"دفعات أغسطس"** ونسبة تحصيل حقيقية لأغسطس.
2. سهم لليمين → **"دفعات سبتمبر"** (0% لأنه بدري).
3. تاريخ 20 سبتمبر (تحصيل مقدّم) → الكارت الافتراضي "دفعات سبتمبر".
4. أرقام الكارت (محصّل/متوقع/متبقّي/عدد لم يدفعوا) مطابقة لشاشة التقارير لنفس الشهر.

### 5. جدول PDF يعرض أيام التسجيل فقط (US5)
1. مجموعة اتسجّلها حضور 8 أيام في شهر 31 يوم → تقرير PDF يعرض **8 أعمدة** بتواريخها.
2. حصة تعويضية في يوم غير معتاد → تظهر كعمود.
3. عدّادات "إجمالي الحضور/الغياب/متأخر" صحيحة رغم تقليص الأعمدة.
4. جدول الواجب PDF → نفس السلوك.
5. مجموعة مفيهاش أي تسجيل الشهر ده → رسالة "لا توجد حصص مسجّلة".

### 6. "شهر التقرير" للامتحان (US6)
1. **Migration**: ثبّت فوق نسخة قديمة → الامتحانات القديمة تفتح عادي، `report_month` = null.
2. اعمل امتحان تاريخه **1/9** → شاشة الإضافة "شهر التقرير" مختار **سبتمبر** افتراضيًا.
3. غيّره لـ**أغسطس** واحفظ.
4. ابعت تقرير واتساب **أغسطس** لطالب في الامتحان ده → الامتحان ودرجته **في الرسالة**.
5. ابعت تقرير **سبتمبر** → الامتحان **مش موجود**.
6. تبويب الامتحانات في صفحة الطالب + تقرير PDF → الامتحان بيتفلتر لأغسطس.
7. امتحان قديم بدون `report_month` → بيتفلتر بتاريخه (زي الأول).
8. وضع الفريق: عدّل "شهر التقرير" على جهاز → يوصل للجهاز التاني.

## بوّابة القبول

سيناريوهات 1–6 تنجح + `flutter analyze` نضيف + migration v22 اشتغلت على جهاز فيه بيانات
قديمة + الامتحانات القديمة سليمة.
