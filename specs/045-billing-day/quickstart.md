# Quickstart: يوم نزول المديونية

## اختبارات الوحدة — `test/billing_day_test.dart`
```bash
flutter test test/billing_day_test.dart
```
جدول السلوك في `contracts/billing-day.md` كامل + التطابق عند 1 + المؤخّر + `monthHasLanded` + شهر مستقبلي + اختبار تكاملي لـ`PricingHelper` (طالب بسعر 100 ومديونية شهر سابق + جاري).

## تحقق يدوي (جهاز)
1. افتراضي 1: الأرقام مطابقة تمامًا لقبل الميزة (داشبورد، مدفوعات، تقارير).
2. الإعدادات ← نظام التحصيل ← "يوم نزول المديونية" ← اختر يوم **بعد** اليوم الحالي: مديونية الشهر الجاري تختفي فورًا من الداشبورد، شاشة المدفوعات، التقارير، تفاصيل الطالب، الـQR، علامة "متأخر".
3. اختر يوم **قبل أو يساوي** اليوم الحالي: الشهر الجاري يرجع محسوبًا كامل.
4. فعّل "التحصيل المؤخّر": الاختيار يتعطّل برسالة، والأرقام تتبع المؤخّر.
5. مهلة سماح 3 ويوم نزول = اليوم الحالي − 1: داخل المهلة لا "متأخر"؛ بعد 3 أيام "متأخر".
6. مجموعة بالحصة: مديونيتها لا تتغير بتغيير اليوم.
7. طباعة المديونيات ثم تغيير اليوم: القائمة تتبع الجديد.
8. بوابة أولياء الأمور: افتح رابط طالب بعد التغيير → المتبقي بالقيمة الجديدة.
9. كارت دفعات الشهر الجاري قبل يوم النزول: لا يعرض "متأخرين".
