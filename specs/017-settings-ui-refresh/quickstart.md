# Quickstart — تحقّق يدوي: واجهة الإعدادات + قناة المجتمع

`flutter analyze` صفر تحذيرات + تحقّق يدوي (نمط specs 009–016).

## بناء وتشغيل

```bash
flutter analyze
flutter run --flavor direct
```

## سيناريوهات

### 1. الترتيب (US1 — FR-001)
افتح تاب الإعدادات، مرّر من فوق لتحت، تأكد من الترتيب:
حالة الترخيص → بيانات المدرس → العملة → **الفوترة والتحصيل** → الواتساب والتقارير → الإشعارات → ماسح QR → الإضافات المدفوعة → المظهر والتوقيت → المساعدين والحسابات → النسخ الاحتياطي → **المجتمع والدعم** → عن التطبيق (الإصدار).

### 2. الفوترة في قسمها (FR-003 / SC-005)
- افتح قسم "الفوترة والتحصيل" → لازم يحتوي: مهلة السماح قبل "متأخر"، تحصيل مؤخّر، حساب نسبي للشهر الأول.
- افتح قسم "الواتساب والتقارير" → **مفيش** أي بند فوترة فيه.
- غيّر "تحصيل مؤخّر" → تأكد إن التنبيه بيظهر والقيمة بتتحفظ (افتح/اقفل الإعدادات، القيمة ثابتة). كرّر لـ"حساب نسبي" و"مهلة متأخر".

### 3. الاتساق البصري (FR-004..006 / SC-003)
- كل قسم له ترويسة بنفس الشكل (أيقونة في مربّع ملوّن + عنوان عريض).
- المسافات بين الأقسام متساوية، الفواصل بين البنود متساوية.
- بدّل للوضع الليلي → كل الأقسام مقروءة بتباين مناسب.
- على شاشة صغيرة (أو تكبير خط النظام) → مفيش نص مقصوص أو متداخل.

### 4. الإضافات المدفوعة (FR-001 بند 7)
- بوابة الأهالي مفعّلة → القسم يعرضها بتاريخ الانتهاء ("تنتهي في X" / "مدى الحياة").
- بوابة الأهالي منتهية → القسم يعرض "انتهت في X" (سبيك 016).
- `canBooking` مفعّل → بند "إعدادات الحجوزات" يفتح `BookingSettingsPage`.
- الإضافتين غير مفعّلتين → القسم يختفي/يقلّ بدون فراغ يكسر الترتيب.

### 5. قناة المجتمع (US2 — FR-008..012)
- في أسفل الشاشة فوق الإصدار: قسم "المجتمع والدعم" فيه شرح + زر أخضر بأيقونة واتساب.
- اضغط الزر (وواتساب مثبّت) → يفتح واتساب على `whatsapp.com/channel/0029VbDFTCsEquiR7nSaO52X`.
- على محاكي بدون واتساب → يفتح المتصفح، أو يظهر "تعذّر فتح القناة" — **التطبيق ما يقعش**.

### 6. صفر تراجع (SC-002 / SC-006)
- عدّ الإعدادات القابلة للتفاعل — كلها موجودة زي قبل + زر القناة.
- جرّب كل تبديل/قائمة منسدلة سريعًا → نفس السلوك والتنبيهات زي قبل.
- `DATABASE_VERSION` لسه 23، مفيش migration جديدة.
