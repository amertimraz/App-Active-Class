# Quickstart: الغياب التلقائي

## اختبارات وحدة
```bash
flutter test test/auto_absent_test.dart
```
تغطي: تحليل نهاية الحصة (عادي، عابر لمنتصف الليل، بلا نهاية، تنسيق خاطئ)، isSessionClosed عند الحدود، lookbackDays، sessionEligible (enabledAt/processed)، studentsToMarkAbsent (مؤرشف، attendanceStart، له سجل)، isAutoAbsent، pruneProcessed.

## تحقق يدوي
1. الإعدادات ← الحضور: المفتاح مطفي والمهلة 15.
2. فعّله، مجموعة حصتها تنتهي بعد دقايق، امسح طالب واحد، سيب الباقي → بعد النهاية + المهلة يتسجّل الباقي "غائب" (ملاحظة "غياب تلقائي") خلال دقيقة.
3. حصة ملغاة / مجموعة بلا وقت نهاية / طالب مؤرشف → لا غياب.
4. امسح QR لطالب اتعلّم تلقائي → يتحوّل حاضر/متأخر.
5. احذف سجل غياب تلقائي يدويًا → ما يرجعش.
6. اقفل التطبيق قبل نهاية الحصة وافتحه بعدها → يتسجّل.
7. طفّي المفتاح → يقف التسجيل.
