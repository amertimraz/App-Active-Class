# Quickstart: التحقق من الحضور بالحصة

## التجهيز
- مجموعة بجدول أسبوعي فيها 10+ طلاب (ويفضّل مجموعة كبيرة 150+ للأداء).
- حضور مسجَّل لبعض الطلاب (حاضر/متأخر/غائب)، وطلاب بدون سجل.
- حصة ملغاة وحصة تعويضية (من شاشة الحضور).

## الاختبارات الآلية
```bash
flutter test test/session_attendance_test.dart test/schedule_week_test.dart test/absence_message_test.dart test/session_detail_page_test.dart
flutter analyze
```

## سيناريوهات يدوية
1. **ملخص الحصة (US1)**: جدول الحصص ← ضغط كارت حصة النهاردة ← الأرقام (حاضر/متأخر/غائب/لم يُسجَّل) تطابق السجلات؛ المجموع = عدد طلاب المجموعة النشطين.
2. **الغايبون + واتساب (US2)**: تبويب "غائب" يعرض الغايبين فقط ← تحديد ← إرسال: يتفتح واتساب لكل ولي أمر بتأكيد/تخطي، والرسالة بتاريخ الحصة؛ طالب بدون رقم يتخطى مع عدّاد.
3. **حصص سابقة (US3)**: في جدول الحصص ← أسبوع سابق/شهر سابق/اختيار تاريخ ← تظهر حصص ذلك اليوم الفعلية ← فتح حصة قديمة يعرض حضورها وقتها؛ تاريخ بدون حصص → "مفيش حصص في اليوم ده"؛ مستقبلي → "لسه ما بدأتش".
4. **تعديل (US4)**: طالب "لم يُسجَّل" ← غائب ← ينتقل لتبويب "غائب" ويزيد العدّاد فورًا؛ "تحضير غير المسجَّلين" يحوّل الباقي لحاضر دون لمس اللي سُجّل.
5. **ملغاة/تعويضية (US5)**: الحصة الملغاة بعلامة "ملغاة" وبدون ملخص/تسجيل؛ التعويضية تظهر في يومها بموعدها الخاص.
6. **تبويب الحضور**: زرار "تفاصيل الحصة" على كارت المجموعة يفتح نفس الشاشة لنفس اليوم؛ الضغط على الكارت نفسه لسه يفتح ورقة التسجيل الحالية؛ "غياب اليوم" يفضل يبعت نفس الرسالة بتاريخ النهاردة (تراجعي).
7. **الأداء**: مجموعة 200 طالب — فتح الشاشة < ثانيتين، التبديل بين التبويبات بلا تقطيع.
8. **الفريق**: من حساب المساعد — الشاشة تعمل وبلا أي مبالغ مالية.
