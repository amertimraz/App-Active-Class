# Contract: واجهة إلغاء/تعويض الحصة + دمج سجل الطالب

## 1. شاشة الحضور (`lib/views/attendance/attendance_page.dart`)

### نقطة الدخول

- في شريط أدوات المجموعة/اليوم (أو قائمة `PopupMenuButton` "⋮"): عنصر **"إلغاء حصة اليوم"** يظهر لو `groupHasSessionOnDay(group, selectedDay)` **بحسب الجدول** (قبل الاستثناء) و**لا** يوجد `cancelled` بالفعل.
- لو يوجد `cancelled` لهذا اليوم: العنصر يصير **"تراجع عن الإلغاء"**.
- عنصر **"إضافة حصة تعويضية / إضافية"** متاح دائمًا (يفتح حوار اختيار النوع + تاريخ يُعوَّض لو makeup).

### حوار الإلغاء

1. لو `countAttendanceForGroupOnDay > 0` → `AlertDialog`: «فيه N حضور مسجّل النهارده. الإلغاء هيمسحهم. تمام؟» [إلغاء] [تأكيد].
2. عند التأكيد: `deleteAttendanceForGroupOnDay` ثم `insertSessionOverride(cancelled)` ثم `soCtrl.load()` + تحديث `AttendanceController` (`refresh`/إعادة حساب).
3. لو المجموعة بلا جدول أصلًا → لا يظهر العنصر (الشرط أعلاه).

### العرض بعد الإلغاء

- رأس القائمة لليوم الملغى: شارة/بانر **"الحصة اتلغت النهارده"** بدل قائمة الطلاب؛ زر "تراجع".
- `makeup`/`extra` في يوم = تُعامل كحصة عادية في شاشة الحضور (قائمة طلاب كاملة) مع لِيبل صغير أعلى القائمة: «حصة معوّضة عن {تاريخ}» / «حصة إضافية».

### الأذونات (team mode)

- الإلغاء/التعويض يتبع نفس إذن تعديل الحضور. لو `!teamMode.canEditAttendanceNow` (إن وُجد؛ وإلا لا قيد) → العناصر مخفية/معطّلة مع "مالكش صلاحية". *(راجع الاسم الفعلي للـgetter في `TeamModeService`؛ لو مفيش getter مخصّص للحضور استخدم منطق الإضافة/التعديل القائم في نفس الشاشة.)*

## 2. تفاصيل الطالب (`lib/views/students/student_details_page.dart`) — دمج عرض فقط

في قسم "سجل الحضور":

```
عناصر = [
  ...attendanceList للطالب,                       // كما هي
  ...cancelledForGroup(student.currentGroupId)     // → عنصر عرض "الحصة اتلغت" بتاريخه
      .map(toDisplayRow),
]
رتّب تنازليًا بالتاريخ.
```

- عنصر حضور تاريخه == تاريخ `makeup`/`extra` لمجموعة الطالب → أضف لِيبل «• حصة معوّضة» / «• حصة إضافية».
- عناصر `cancelled` **لا** تدخل حساب نسبة الحضور/عدد الحصص.
- طالب بلا مجموعة حالية أو انتقل بين مجموعات → استثناءات مجموعته الحالية فقط (قيد موثّق).

## 3. بوابة الأهل (`lib/services/parent_portal_service.dart`)

- في بناء `attendanceHistory` (المدفوعة فقط): أضف عناصر `cancelled` لمجموعة الطالب كـ «تم إلغاء الحصة» بتاريخها، ولِيبل «حصة تعويضية» على صفوف الحضور المطابقة.
- لا تغيير في حسابات المبالغ/المديونية المعروضة (مبنية على الحضور الفعلي).

## 4. التسجيل (`main.dart` / bindings)

- `Get.put(SessionOverrideController(), permanent: true)` مع بقية الـcontrollers الأساسية، و`load()` عند فتح شاشة الحضور وتفاصيل الطالب (زي `AttendanceController._payCtrl.loadPayments()` في spec 029).

## 5. لا واجهة لـ

- لا شاشة إدارة مركزية لكل الاستثناءات (نطاق لاحق). الإدارة من شاشة الحضور لكل يوم.
