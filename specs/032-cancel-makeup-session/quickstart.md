# Quickstart: إلغاء حصة اليوم وتعويضها

## سيناريوهات القبول

### 1. إلغاء حصة اليوم (بلا حضور مسجّل)
1. افتح الحضور، مجموعة لها حصة النهارده بالجدول.
2. "⋮" → "إلغاء حصة اليوم" → تأكيد.
3. **متوقّع**: القائمة تُستبدَل بـ"الحصة اتلغت النهارده" + زر "تراجع". المجموعة لا تُحسب في "الحصص المتوقّعة" للأسبوع/الشهر.

### 2. إلغاء وفيه حضور مسجّل
1. سجّل حضور 3 طلاب، ثم "إلغاء حصة اليوم".
2. **متوقّع**: حوار «فيه 3 حضور... هيتمسحوا. تمام؟». عند التأكيد تُمسح الـ3 صفوف ويُنشأ `cancelled`. مزامنة الفريق تتلقّى حذف الـ3 + الاستثناء.

### 3. تراجع عن الإلغاء
1. بعد سيناريو 1: "⋮" → "تراجع عن الإلغاء".
2. **متوقّع**: الاستثناء يُحذف، القائمة تعود، العدّ المتوقّع يرجع كما كان.

### 4. حصة تعويضية في يوم مش بالجدول
1. مجموعة جدولها السبت. اليوم الثلاثاء. "⋮" → "إضافة حصة تعويضية" → اختر "تعويض عن" = السبت الماضي.
2. **متوقّع**: شاشة الحضور تعرض قائمة طلاب المجموعة كاملة النهارده مع لِيبل «حصة معوّضة عن {السبت}». الحضور المسجّل يُحتسب في الفوترة per-session كحصة عادية.

### 5. طالب per-session — الفوترة
1. طالب سعره 50، حصّل حصتين هذا الشهر (مستحق 100).
2. أُلغيت حصة كان حاضرًا فيها (سيناريو 2) → المستحق يرجع 50 تلقائيًا (لا كود فوترة).
3. حضر حصة تعويضية → المستحق يرجع 100.
4. **متوقّع**: `PricingHelper.accumulatedDebt` صحيح بلا أي تعديل عليه. رصيد مدفوع مقدّمًا لحصة أُلغيت يصير رصيد FIFO للتالية.

### 6. سجل الطالب
1. افتح تفاصيل طالب مجموعته فيها إلغاء + تعويض.
2. **متوقّع**: قسم الحضور يعرض «الحصة اتلغت — {تاريخ}» (لا يُحتسب في النسبة) وصف الحضور التعويضي عليه «• حصة معوّضة». الترتيب تنازلي بالتاريخ.

### 7. مزامنة الفريق
1. المدرّس يلغي حصة؛ المساعد يفتح التطبيق.
2. **متوقّع**: خلال ≤ دورة catch-up، المساعد يرى نفس الإلغاء. لو الاثنان أنشآ استثناء لنفس `(group, date)` → `_reconcileDuplicate` (spec 031) يطبّق LWW، لا تكرار.

### 8. عدم الانحدار
1. مجموعة بلا أي استثناءات.
2. **متوقّع**: كل أعداد الحضور المتوقّعة وقوائم الأيام مطابقة تمامًا لما قبل spec 032.
