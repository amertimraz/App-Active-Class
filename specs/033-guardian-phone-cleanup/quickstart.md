# Quickstart: تنظيف رقم ولي الأمر + واتساب

## سيناريوهات القبول

### 1. لصق رقم بمسافات
1. إضافة طالب → حقل رقم ولي الأمر → الصق `+20 100 123 4567`.
2. **متوقّع**: الحقل يعرض `+201001234567` (أو `01001234567`) بمحاذاة يسار، **غير معكوس**. معاينة:
   «هيتبعت على: ‎+20 100 123 4567».

### 2. لصق رقم بأرقام عربية
1. الصق `٠١٠٠١٢٣٤٥٦٧`.
2. **متوقّع**: يتحوّل فورًا لـ`01001234567`. لا تحذير.

### 3. لصق رقم فيه علامات اتجاه مخفية
1. من سجل مكالمات أندرويد عربي، الصق رقمًا (غالبًا فيه U+200E/U+200F).
2. **متوقّع**: العلامات تُزال، الرقم نظيف، غير معكوس.

### 4. رقم ناقص
1. اكتب `123`.
2. **متوقّع**: تحذير برتقالي «الرقم يبدو غير مكتمل». زر الحفظ **يشتغل** (غير معطِّل).

### 5. اتساق الإرسال عبر الشاشات
1. احفظ طالبًا برقم صحيح.
2. افتح رسالة واتساب من: شاشة الحضور، درجات الامتحان، التقارير، متأخرو السداد، تفاصيل الطالب.
3. **متوقّع**: واتساب يفتح على **نفس** الرقم الصحيح في كل الشاشات.

### 6. رقم قديم ملوّث
1. طالب رقمه المخزّن `01001234567 ` (بمسافة) أو `+2 010...` من قبل الميزة.
2. افتح رسالة واتساب له.
3. **متوقّع**: يفتح صح — بدون إعادة إدخال (التطبيع لحظة الإرسال).

### 7. رابط واتساب (US3)
1. عدّل طالبًا بلا رقم → حقل «واتساب ولي الأمر» = `https://wa.me/message/ABC123`.
2. اضغط أيقونة واتساب.
3. **متوقّع**: يفتح هذا الرابط مباشرة.

### 8. اسم مستخدم (US3)
1. حقل الواتساب = `@ahmed_dad`. اضغط أيقونة واتساب.
2. **متوقّع**: يفتح واتساب، الرسالة **تُنسخ للحافظة**، توست «اتنسخت الرسالة — الصقها في شات ولي الأمر».

### 9. أولوية الرابط على الرقم (US3)
1. طالب عنده رقم **و** رابط `wa.me` في حقل الواتساب.
2. اضغط أيقونة واتساب.
3. **متوقّع**: يُفتح الرابط (لا الرقم).

### 10. عدم الانحدار
1. طالب عنده رقم صحيح وحقل واتساب فارغ.
2. **متوقّع**: كل أزرار الواتساب تعمل بنفس السلوك السابق بالضبط.

### 11. مزامنة الفريق (US3)
1. المدرّس يضيف `guardian_whatsapp` لطالب.
2. **متوقّع**: المساعد يشوف القيمة خلال دورة مزامنة (زي `guardian_phone`).

```bash

  "docker exec -i active-class-auth-db-1 psql -U postgres -d postgres -v ON_ERROR_STOP=1" \
  < supabase/migration_guardian_whatsapp.sql
# تحقّق: \d public.students → عمود guardian_whatsapp text
```

## المخاطر

- **موضع المؤشر** بعد الـformatter: نضعه في النهاية دائمًا — مقبول لأرقام قصيرة؛ لو أزعج، نحسّنه لاحقًا.
- **عمود Supabase قبل نشر التطبيق**: `add column if not exists` آمن؛ التطبيق القديم يتجاهل العمود.
- تجميع خانات `displayIntl` تقريبي لغير مصر — تجميلي فقط، لا يؤثر على `waMe`.
