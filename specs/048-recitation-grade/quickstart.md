# Quickstart: درجة التسميع

## اختبارات وحدة
```bash
flutter test test/recitation_test.dart
```
تغطي: normalizeRecitation (حدود 1/10، 0، 11، null)، canRecordRecitation، recitationAverage (إجمالي/شهر، تجاهل الفارغ والمرفوض، التقريب، null)، recitationCount، المسح عند الغياب (copyWith)، الحفاظ عند حاضر⇄متأخر.

## تحقق يدوي (جهاز)
1. حضور اليوم ← مجموعة ← حضّر طالب → يظهر صف "تسميع 1–10" تحت التفاعل. اختر 8 → يتلوّن.
2. اضغط 8 تاني → يتمسح. اختر 6 ثم 9 → يستبدل.
3. حوّل الطالب لغائب → الصف يختفي والدرجة تتمسح؛ رجّعه حاضر → بلا درجة.
4. حاضر ⇄ متأخر → الدرجة تفضل.
5. "إلغاء تحضير الكل" → الدرجات تتمسح مع السجلات.
6. تفاصيل الطالب ← سجل الحضور: الدرجة بجانب اليوم، وبطاقة متوسط الشهر والإجمالي؛ طالب بلا درجات: لا بطاقة.
7. نسب الحضور والمديونية بدون تغيير.
8. وضع الفريق: درجة من المساعد تظهر عند المدرس بعد المزامنة (بعد تطبيق migration).
