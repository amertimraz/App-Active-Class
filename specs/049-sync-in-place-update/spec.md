# Spec 049 — منع تكرار صفوف المزامنة عند تغيّر هوية الجهاز

**Status**: Implemented (v1.2.74، لم يُنشر بعد) — تشخيص + تصليح بدون spec كامل لأنه حادثة إنتاج.

## المشكلة
هوية الجهاز (ANDROID_ID) بتتغيّر مع اختلاف توقيع الـAPK/إعادة التثبيت. كل تعديل لصف متزامن كان بيتبعت بـupsert على (team, origin_device_id, local_id) فبيتولّد صف مكرر على السيرفر ويستلمه باقي الفريق (مجموعة "Grade 2 (2)" + طلاب "-2").
مثال حقيقي: فريق بـ4 هويات على 6 أسابيع، 208 طالب منهم 179 اسم مختلف.

## الإصلاح
- الصف اللي ليه remote_id يتحدّث بالـid على السيرفر (`inPlaceUpdateColumns` تشيل مفاتيح الأصل)، وإلا يرجع للـupsert.
- الاسم/الكود المعدّلين محليًا بسبب تعارض (لاحقة) ما بيترفعوش.
- التنظيف اليدوي لفريق متأثر: سكريبت SQL بنسخة احتياطية + soft delete (يُنفَّذ بموافقة المستخدم بعد تحديث الأجهزة).
