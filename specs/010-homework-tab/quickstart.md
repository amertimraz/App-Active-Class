# Quickstart / التحقق: تبويب واجب + 3 حالات + ربط الغياب + التقارير

**Feature**: 010-homework-tab

## المتطلبات

- جهاز Android، فلافور `direct`.
- بيانات: مجموعة ليها حصة النهاردة + عدة طلاب؛ طالب له بوابة أولياء أمور مفعّلة؛ سجلات واجب قديمة (`'عمل'`/`'لم يعمل'`) على يوم سابق.
- `flutter build apk --debug --flavor direct` ثم `adb install -r ...`.

## 1 — الموديل يفتح على "حضور" وجنبه "واجب" (FR-001, FR-015)

اضغط كارت مجموعة → يفتح على "حضور"، وفوق القائمة شريط تبويبين "حضور · واجب" فقط. تبويبات الصفحة نفسها زي ما هي.

## 2 — تبويب "حضور" نضيف من الواجب (FR-003, FR-010, SC-002)

صف الطالب فيه أزرار الحضور فقط. صف الأزرار الجماعية فيه "تحضير الكل" فقط — لا "واجب الكل".

## 3 — 3 حالات صريحة (FR-004..FR-006, SC-004)

تبويب "واجب" → تحت اسم كل طالب (غير غائب): 3 أزرار 🟢 تم الحل · 🟡 ناقص · 🔴 لم يُحل.
- اضغط "ناقص" → يتحدد هو فقط، ويتحفظ.
- اضغط "لم يُحل" → ينتقل مباشرة، "ناقص" يتلغي.
- اضغط "لم يُحل" تاني (المختار) → يرجع "غير مسجّل" (مفيش زر مختار).

## 4 — الزر الجماعي يستثني الغائبين (FR-009)

سجّل طالب غائب في تبويب "حضور" → ارجع "واجب" → اضغط "الكل عمل" → كل الطلاب "تم الحل" **ماعدا الغائب**.

## 5 — ربط الغياب (FR-007, SC-006)

1. تبويب "واجب" → سجّل لطالب "تم الحل".
2. تبويب "حضور" → سجّل نفس الطالب **غائب**.
3. ارجع "واجب" → صف الطالب يعرض **"غائب — لا واجب"** (بدون أزرار)، والملخّص مابيعدّهوش.
4. تبويب "حضور" → رجّعه **حاضر** → "واجب" → الأزرار الـ3 رجعت **فارغة** (مش "تم الحل" القديمة).

## 6 — الملخّص (FR-011)

رأس تبويب "واجب": `تم الحل: X · ناقص: Y · لم يُحل: Z · غير مسجّل: W` — بيتحدّث فورًا مع كل ضغطة، ومابيعدّش الغائبين.

## 7 — البيانات القديمة (FR-014, SC-005)

روح ليوم قديم فيه سجلات `'عمل'`/`'لم يعمل'` → تبويب "واجب" → تظهر كـ**"تم الحل"**/**"لم يُحل"** صح.

## 8 — حالة الواجب في كل التقارير (FR-012, FR-013, SC-007, SC-009)

1. **تقرير الحصة/اليوم لطالب** (زر واتساب في الموديل / تبويب تسجيل): الرسالة فيها سطر `📖 الواجب: 🟡 ناقص` (أو الحالة المناسبة، أو `غائب (لا واجب)`، أو `لم يُسجَّل`).
2. **التقرير الشهري** (من تفاصيل الطالب / الإعدادات): عدّادات 3 حالات + سطور الأيام بالتسمية الصح.
3. **بوابة أولياء الأمور**: بعد تغيير حالة → البوابة تتحدّث خلال ثوانٍ وتعرض القيمة الجديدة (ومنها "ناقص").

## 9 — عدم انحدار

تسجيل حضور مجموعة كاملة من "حضور" + إرسال تقرير جماعي — كله زي ما كان.
