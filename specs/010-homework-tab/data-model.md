# Data Model: تبويب واجب داخل موديل المجموعة

**Feature**: 010-homework-tab

## تغيير واحد صغير: قيمة حالة نصّية جديدة — **بدون هجرة**

### `Homework` (جدول `homework`) — بنية الجدول بدون تغيير

| الحقل | النوع | ملاحظة |
|-------|------|--------|
| `id` | int | |
| `student_id` | int | |
| `date` | ISO datetime | يوم التسجيل (= يوم الحصة عادةً) |
| `status` | نص | **كان**: `'عمل'` / `'لم يعمل'`. **يبقى**: `'تم الحل'` / `'ناقص'` / `'لم يُحل'` |
| `created_at` | ISO datetime? | |

**التوافق مع البيانات القديمة** (طبقة عرض، لا كتابة):
- `'عمل'` → تُعرض وتُحسب كـ`'تم الحل'`
- `'لم يعمل'` → تُعرض وتُحسب كـ`'لم يُحل'`
- (`'ناقص'` قيمة جديدة، مفيش بيانات قديمة بها)

الكتابة الجديدة تستخدم القيم الجديدة فقط. القراءة تطبّع القديم للجديد.

### الحالات وانتقالاتها (جديد)

```
غير مسجّل ──[زر تم الحل]──▶ تم الحل ──[نفس الزر]──▶ غير مسجّل
غير مسجّل ──[زر ناقص]────▶ ناقص    ──[نفس الزر]──▶ غير مسجّل
غير مسجّل ──[زر لم يُحل]──▶ لم يُحل  ──[نفس الزر]──▶ غير مسجّل
(الضغط على زر مختلف = انتقال مباشر لحالته، بدون وسيط)
```
- "غير مسجّل" = لا سجل في الجدول (زي دلوقتي).
- تسجيل الطالب **غائب** ⇒ حذف سجل واجبه لنفس اليوم (لو موجود)، وإخفاء الأزرار.

## بدون هجرة

`DATABASE_VERSION` يفضل زي ما هو. لا أعمدة/جداول جديدة. البيانات التاريخية تُقرأ عبر التطبيع أعلاه.
